# Your Alexa bridge: cheat sheet

Replace <name> with your skill's name, for example “Nova AI”.

| You want to… | Say |
| --- | --- |
| Ask anything | “Alexa, ask <name>, please …” |
| Use another opening | “Alexa, ask <name> to tell me …”, “… to explain …”, “… what …” |
| Link the Echo you're talking to | “Alexa, ask <name> to link this Echo”, then the Echo's exact name |
| Hear what happened to your last request | “Alexa, ask <name> to check cloud status” |
| Retry Amazon sign-in renewal | “Alexa, ask <name> to renew cloud authentication” |
| Stop a pending answer | “Alexa, ask <name> to cancel” |

**Good to know**

- **First time on an Echo:** if it isn't linked yet, Alexa asks “Which Echo is this?”. Say the Echo's exact name, as shown in the Alexa app, within two minutes. Alexa then links it and sends the question you just asked, so you don't need to repeat it. If you say cancel, or wait too long, nothing is sent.
- Include your request in the same sentence for the quickest answer. “Alexa, open <name>” also works: it asks what you'd like to ask.
- After “Okay, one moment.”, the answer arrives on the same Echo when it's ready. Wait for it before asking something new; a newer request on the same Echo replaces the older answer.
- Answers that are too long aren't cut off, so ask for a short answer (“in three sentences”).
- An answer is never repeated automatically if delivery was uncertain. Check the status before asking again, especially for requests that make your bot do something.
- Turn on **Adaptive Listening** for each Echo (Alexa app → Settings → Accessibility) to have more time to finish speaking.
- If Alexa says sign-in needs attention, ask your agent to “run Alexa bridge maintenance”.
